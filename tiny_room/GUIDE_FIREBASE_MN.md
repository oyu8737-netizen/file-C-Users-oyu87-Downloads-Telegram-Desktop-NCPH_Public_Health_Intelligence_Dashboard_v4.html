## Алхам 0. Шинэ кодоо компьютер руугаа татах

**PowerShell** нээгээд (⊞ → `powershell` → Enter) дараах **нэг мөрийг** хуулж тавиад Enter дарна:

```powershell
cd $HOME\tiny-room-repo; git stash -u; git pull; cd tiny_room; flutter pub get
```

| Хэсэг | Юу хийнэ | Яагаад |
|---|---|---|
| `cd $HOME\tiny-room-repo` | Кодын хавтас руу орно | |
| `git stash -u` | Таны компьютер дээр өмнө нь үүссэн файлуудыг (жишээ нь өмнө нь гараар нэмсэн `web` хавтас) **түр хадгалж** хажуу тийш тавина | Эс тэгвээс шинэ кодтой "мөргөлдөж" татахгүй. Устгахгүй, хадгална |
| `git pull` | GitHub-аас **шинэ кодыг** татна | |
| `cd tiny_room` | Аппын хавтас руу орно | |
| `flutter pub get` | Шинэ сангуудыг (Firebase, алхам тоологч) татна | `pubspec.yaml` дотор шинэ сангууд нэмэгдсэн |

✅ Сүүлд `Got dependencies!` гарвал болсон.

**Одоо шууд туршиж үзэх** (Firebase-гүй):
```powershell
flutter run -d chrome
```

## Алхам 1. Firebase төсөл үүсгэх

1. Chrome дээр **https://console.firebase.google.com** руу орж Google бүртгэлээрээ нэвтэрнэ.
2. **Create a project** (эсвэл **Add project**) дарна.
3. Нэр: `tiny-room` гэж бичээд **Continue**.
4. **Google Analytics** асуувал → **Enable** хэвээр үлдээгээд **Continue**.
   > **Яагаад?** Хэдэн хүн өдөр бүр апп ашиглаж байгааг, аль улсаас гэх мэтийг автоматаар тоолно.
5. **Analytics location**: Mongolia, эсвэл жагсаалтад байгаа аль нэгийг сонгож, нөхцөлийг зөвшөөрөөд **Create project**.
6. 30 секунд орчим хүлээгээд **Continue** дарна.

✅ Firebase-ийн хяналтын самбар нээгдэнэ.

## Алхам 2. Account (нэвтрэх) асаах

1. Зүүн цэснээс **Build → Authentication** → **Get started**.
2. **Sign-in method** таб → **Email/Password** дээр дарна.
3. Эхний **Enable** товчийг асаагаад → **Save**.

**Яагаад:** Хэрэглэгчид имэйл, нууц үгээр бүртгүүлэх боломжтой болно. Нууц үгийг Google аюулгүй хадгалдаг. Бид өөрсдөө хадгалахгүй.

---

## Алхам 3. Мэдээллийн сан (Firestore) үүсгэх

1. Зүүн цэснээс **Build → Firestore Database** → **Create database**.
2. **Location**: `asia-east2 (Hong Kong)` эсвэл `asia-northeast1 (Tokyo)` сонгоно.
   > **Яагаад?** Монголд ойр сервер тул апп хурдан ажиллана. ⚠️ Дараа нь өөрчлөх боломжгүй.
3. **Start in production mode** сонгоод → **Create**.
4. Дээд талын **Rules** таб руу шилжинэ.
5. Тэнд байгаа бичгийг **бүгдийг устгаад**, GitHub дээрх [`tiny_room/firestore.rules`](firestore.rules) файлын **бүх агуулгыг** хуулж тавина.
6. **Publish** дарна.

**Яагаад дүрэм хэрэгтэй вэ?** Дүрэмгүй бол хэн ч бусдын өгөгдлийг уншиж, өөрчилж чадна. Манай дүрэм:
- Өөрийн өгөгдлөө **зөвхөн өөрөө** өөрчилнө.
- Таны өрөө, алхмыг **зөвхөн найзууд** тань харна.
- Нийт хэрэглэгчийн тоог **зөвхөн admin** (та) харна.

> Эрүүл мэндийн өгөгдөлтэй ажиллаж байгаа тул энэ маш чухал.

## Алхам 4. Хэрэгслүүд суулгах (нэг удаа)

Аппыг Firebase-тэй холбоход **2 хэрэгсэл** хэрэгтэй:
- **Firebase CLI** — таны компьютерээс Firebase руу нэвтрэх хэрэгсэл
- **FlutterFire CLI** — Firebase-ийн тохиргоог аппын код руу автоматаар бичих хэрэгсэл

**PowerShell** дээр доорх хайрцгийг бүхэлд нь хуулж тавиад Enter дарна. 5–10 минут орно:

```powershell
& {
  Write-Host "=== 1/3: Node.js суулгаж байна ===" -ForegroundColor Cyan
  if (-not (Get-Command node -ErrorAction SilentlyContinue)) {
    winget install --id OpenJS.NodeJS.LTS -e --accept-package-agreements --accept-source-agreements
    $env:Path += ";C:\Program Files\nodejs"
  } else { Write-Host "Node.js байна ✓" }

  Write-Host "=== 2/3: Firebase CLI суулгаж байна ===" -ForegroundColor Cyan
  npm install -g firebase-tools
  $env:Path += ";$env:APPDATA\npm"

  Write-Host "=== 3/3: FlutterFire CLI суулгаж байна ===" -ForegroundColor Cyan
  dart pub global activate flutterfire_cli
  $pubBin = "$env:LOCALAPPDATA\Pub\Cache\bin"
  $userPath = [Environment]::GetEnvironmentVariable('Path', 'User')
  if (($userPath -split ';') -notcontains $pubBin) {
    [Environment]::SetEnvironmentVariable('Path', ($userPath.TrimEnd(';') + ';' + $pubBin), 'User')
  }
  Write-Host "`n🎉 БОЛЛОО! PowerShell-ээ хаагаад шинээр нээнэ үү." -ForegroundColor Green
}
```

| Хэсэг | Яагаад |
|---|---|
| Node.js | Firebase CLI нь Node.js дээр ажилладаг программ |
| `npm install -g firebase-tools` | Firebase CLI-г суулгана (`npm` = Node-ийн "апп дэлгүүр") |
| `dart pub global activate flutterfire_cli` | FlutterFire CLI-г суулгана |
| PATH-д нэмэх | `flutterfire` тушаалыг Windows олдог болгоно (Flutter-т хийсэнтэй адил) |

> ⚠️ "`npm` cannot be loaded because running scripts is disabled" гэж гарвал:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
> гээд `Y` дарж, дээрх хайрцгийг дахин ажиллуулна. (Windows анхандаа скрипт ажиллуулахыг хориглодог.)

## Алхам 5. Аппыг Firebase-тэй холбох

**Шинэ** PowerShell нээгээд, мөр бүрийг **нэг нэгээр нь** ажиллуулна:

**5.1** Firebase руу нэвтрэх:
```powershell
firebase login
```
> Chrome нээгдэнэ → Алхам 1-д ашигласан Google бүртгэлээ сонгоно → **Allow**.
> "Allow Firebase to collect CLI usage?" гэж асуувал `n` гэж бичиж болно.

**5.2** Аппын хавтас руу орох:
```powershell
cd $HOME\tiny-room-repo\tiny_room
```

**5.3** Холбох:
```powershell
flutterfire configure --platforms=android,ios,web
```
- Төслийн жагсаалт гарна → сум товчоор **tiny-room**-ийг сонгоод **Enter**.
- Бусад асуулт гарвал **Enter** (үндсэн сонголт) дарна.

**Яагаад:** Энэ тушаал Firebase дээр таны аппыг (Android, iPhone, вэб) бүртгүүлж, холболтын мэдээллийг `lib/firebase_options.dart` файлд **автоматаар** бичнэ. Энэ файл өмнө нь "түр зуурын" байсан, одоо жинхэнэ болно.

✅ `Firebase configuration file lib/firebase_options.dart generated successfully` гарвал болсон.

**5.4** Туршиж үзэх:
```powershell
flutter run -d chrome
```
Одоо апп **нэвтрэх дэлгэцээр** эхэлнэ:
1. **Бүртгүүлэх** табыг сонгоно.
2. Нэр, имэйл, нууц үгээ (6+ тэмдэгт) оруулаад **Бүртгүүлэх** дарна.
3. **Найзууд** таб руу ороход **таны 6 үсэгтэй найзын код** харагдана. 🎉

## Алхам 6. Өөрийгөө admin болгох

"Хэдэн хүн хэрэглэж байна" гэдгийг апп дотроос харахын тулд өөрийгөө admin болгоно.

1. Firebase Console → **Authentication** → **Users** таб.
2. Таны имэйлийн мөрөнд байгаа **User UID**-ийн (урт үсэг, тоо) хажууд очиж **хуулах 📋** дүрс дарна.
3. **Firestore Database** → **Data** таб → **+ Start collection**.
4. **Collection ID**: `admins` → **Next**.
5. **Document ID**: хуулсан **UID**-ээ тавина.
6. **Field**: `role`, **Type**: string, **Value**: `admin` → **Save**.
7. Аппаа дахин нээнэ (PowerShell дээр `R`).
8. **Би** таб → **📈 Хэрэглэгчийн статистик** гарч ирнэ!

**Яагаад гараар?** Хэн admin болохыг апп дотроос өөрчлөх боломжтой бол хэн ч өөрийгөө admin болгож чадна. Тиймээс зөвхөн Firebase Console-оос, зөвхөн та л нэмж чадна.

## Алхам 7. Утсан дээр жинхэнэ алхам тоолуулах

Жинхэнэ алхам **зөвхөн утсан дээр суулгасан аппад** ажиллана. Вэб эсвэл Chrome дээр ажиллахгүй.

### 📱 Android утас (Windows компьютер хангалттай)

1. Утсан дээр: **Settings → About phone** → **Build number** дээр **7 удаа** дарна → "You are now a developer!" гарна.
2. **Settings → Developer options** → **USB debugging**-ийг асаана.
3. Утсаа USB кабелиар компьютерт холбоно → утсан дээр **"Allow USB debugging?"** гэж асуувал → **Allow**.
4. PowerShell дээр:
   ```powershell
   cd $HOME\tiny-room-repo\tiny_room
   flutter run
   ```
5. Апп утсан дээр суугаад нээгдэнэ → **Гэр** таб → **Алхам холбох** → зөвшөөрнө.

**Health Connect гэж юу вэ?** Android-ийн алхам, зүрхний цохилт зэргийг хадгалдаг сан. Android 14-өөс дээш утсанд **суучихсан** байдаг. Хуучин утсанд **Health Connect суулгах** товч гарна. Суулгахгүй бол апп утасны **мэдрэгчээр** өөрөө тоолно, гэхдээ апп нээлттэй үед л тоолно.

### 🍎 iPhone (Mac компьютер хэрэгтэй)

iPhone дээр **Apple Health**-ээс алхам уншихад Apple-ийн дүрмээр Mac + Xcode заавал хэрэгтэй.
Mac дээр:
```bash
cd tiny_room
flutter run
```
Эхний удаа Xcode → **Runner** → **Signing & Capabilities** → **Team**-ээ сонгоно. HealthKit тохиргоо (`Runner.entitlements`) бэлэн хийгдсэн.
> HealthKit ашиглахад Apple Developer бүртгэл ($99/жил) шаардагдаж магадгүй.

> **Яагаад?** Firebase зөвхөн зөвшөөрсөн вэб хаягаас нэвтрэхийг зөвшөөрдөг. Нэмэхгүй бол вэб хувилбар дээр нэвтрэх үед алдаа гарна.

## Апп дэлгүүрт гаргахаас өмнө

Эрүүл мэндийн (алхам) өгөгдөл ашиглаж байгаа тул:
- **Нууцлалын бодлого (Privacy Policy)** хуудас заавал хэрэгтэй. Ямар өгөгдөл цуглуулж, хаана хадгалж, хэнтэй хуваалцдаг вэ гэдгийг бичнэ. Apple, Google хоёулаа шаарддаг.
- Google Play дээр **Health Connect-ийн зөвшөөрөл**-ийн хүсэлтийг тусад нь бөглөнө.
- Хэрэглэгч account-аа **устгах** боломжтой байх ёстой (Apple-ийн шаардлага). Энэ нь дараагийн хувилбарт нэмэгдэнэ.

## Алдаа гарвал

| Алдаа | Шалтгаан | Шийдэл |
|---|---|---|
| `git pull` дээр "conflict" / "would be overwritten" | Компьютер дээрх өөрчлөлт | `git stash -u` хийсэн эсэхээ шалгаад дахин `git pull` |
| `'flutterfire' is not recognized` | PATH | PowerShell-ээ хаагаад шинээр нээ. Болохгүй бол Алхам 4-ийг дахин |
| `'firebase' is not recognized` | Node/npm PATH | PowerShell-ээ шинээр нээ. `node -v` ажиллаж байгаа эсэхийг шалга |
| Апп дээр "Firebase тохируулах хэрэгтэй" гэсээр | `flutterfire configure` хийгдээгүй | Алхам 5.3 |
| Нэвтрэхэд `(operation-not-allowed)` | Email/Password асаагаагүй | Алхам 2 |
| `permission-denied` | Firestore дүрэм тавиагүй | Алхам 3.4–3.6 |
| Admin статистик харагдахгүй | admins баримт буруу UID-тэй | Алхам 6 — UID яг таарч байгааг шалга, аппаа дахин нээ |
| Вэб дээр нэвтрэхэд `unauthorized-domain` | Netlify домэйн нэмээгүй | Алхам 8-ын ⚠️ |

Алдааны мессежийг **бүтнээр нь хуулж**, эсвэл **дэлгэцийн зургийг** Claude-д илгээвэл хамгийн хурдан шийдэгдэнэ.
