## 0. Эхлээд ойлгох 7 үг

Эрүүл мэндийн судалгаатай зүйрлэвэл ойлгоход амар.

| Үг | Энгийнээр | Зүйрлэл |
|---|---|---|
| **Код** | Компьютерт өгөх алхам алхмаар бичсэн заавар | Эмчилгээний протокол |
| **Dart** | Кодоо бичиж буй *хэл* | Протоколыг бичсэн хэл (англи, монгол) |
| **Flutter** | Dart кодыг iPhone, Android апп болгон хувиргадаг *хэрэгсэл* | Протоколыг бодит эмнэлгийн үйлдэл болгодог баг |
| **SDK** | Flutter-ийн бүх хэрэгслийг нэг дор багцалсан програм | Лабораторийн бүх тоног төхөөрөмж |
| **Emulator** | Компьютер дотор ажилладаг *хийсвэр утас* | Симуляцийн сургалтын манекен |
| **Git / GitHub** | Кодын өөрчлөлт бүрийг хадгалдаг систем / түүний онлайн сан | Судалгааны өгөгдлийн хувилбарууд + онлайн архив |
| **Terminal** | Хулгана биш, *текст бичиж* компьютерт тушаал өгөх цонх | Лабораторийн төхөөрөмжид шууд команд өгөх |

## 1-р хэсэг. Компьютерээ бэлдэх

Энэ хэсгийг **зөвхөн нэг удаа** хийнэ. Нийт 1–2 цаг орно (ихэнх нь татах хугацаа).

### Алхам 1.1 — Git суулгах

**Юу хийх:** https://git-scm.com/download/win → татаж суулгана. Суулгах үеийн бүх асуултад **Next** дарахад болно.

**Яагаад:** Код GitHub дээр хадгалагдаж байгаа. Түүнийг компьютер руугаа татахын тулд Git хэрэгтэй. Мөн Flutter өөрөө дотроо Git ашигладаг тул Git-гүйгээр Flutter ажиллахгүй.

---

### Алхам 1.2 — VS Code суулгах

**Юу хийх:** https://code.visualstudio.com → **Download for Windows** → суулгана.

**Яагаад:** Кодыг Notepad-оор ч бичиж болно. Гэхдээ VS Code нь:
- кодыг өнгөөр ялгаж харуулна (уншихад амар),
- алдааг улаанаар зурж заана (эмчийн "анхааруулга" шиг),
- доторх **terminal** цонхоор тушаал бичих боломж өгнө.

---

### Алхам 1.3 — VS Code-д Flutter extension нэмэх

**Юу хийх:**
1. VS Code-оо нээнэ.
2. Зүүн талын **дөрвөлжин дүрс** (Extensions) дээр дарна, эсвэл `Ctrl + Shift + X`.
3. `Flutter` гэж хайгаад **Install** дарна (Dart extension дагаад суучихна).

**Яагаад:** VS Code анхандаа Dart хэлийг "мэдэхгүй". Extension нь VS Code-д Dart хэлийг ойлгож, Flutter аппыг ажиллуулах товчнуудыг нэмж өгдөг. Толь бичиг суулгаж байгаатай адил.

---

### Алхам 1.4 — Flutter SDK суулгах

**Юу хийх:**
1. VS Code дээр `Ctrl + Shift + P` дарна. Дээд талд хайлтын мөр гарна.
2. `Flutter: New Project` гэж бичээд Enter.
3. "Could not find a Flutter SDK" гэсэн мэдэгдэл гарвал **Download SDK** дарна.
4. Хадгалах газар сонгоно: `C:\dev` гэх мэт **зай, монгол үсэггүй** хавтас сонгоорой.
5. Дууссаны дараа **Add SDK to PATH** гэж асуувал **заавал дарна**.
6. VS Code-оо хаагаад дахин нээнэ.

**Яагаад:**
- **SDK** бол Dart кодыг апп болгон хөрвүүлэх "үйлдвэр". Үүнгүйгээр код зүгээр л текст хэвээр үлдэнэ.
- **`C:\dev` гэж яагаад?** `C:\Program Files` шиг *зайтай*, эсвэл монгол үсэгтэй замд Flutter алдаа гаргадаг.
- **PATH гэж юу вэ?** Windows-т "`flutter` гэсэн тушаал ирвэл энэ хавтсаас хай" гэж хэлж өгч байгаа хаяг. Үүнгүй бол terminal дээр `flutter` гэж бичихэд *"танигдахгүй тушаал"* гэсэн алдаа гарна.
- **Дахин нээх нь яагаад?** Шинэ PATH зөвхөн шинээр нээсэн цонхонд л хүчинтэй болдог.

---

### Алхам 1.5 — Android Studio суулгах

**Юу хийх:** https://developer.android.com/studio → татаж суулгана. Анх нээхэд **Standard** сонголтоор бүх зүйлийг суулгуулна.

**Яагаад:** Бид Android Studio-г код бичихэд *ашиглахгүй* (VS Code ашиглана). Гэхдээ дотор нь:
- **Android SDK** — Android утсанд зориулж апп бүтээх хэрэгсэл,
- **Emulator** — компьютер доторх хийсвэр утас

байдаг. Эдгээрийг авахын тулд л суулгаж байна.

> 📱 **iPhone яах вэ?** iPhone-д зориулсан апп бүтээхэд Apple зөвхөн **Mac компьютер + Xcode** зөвшөөрдөг. Windows дээр боломжгүй. Код нь ижилхэн, зөвхөн бүтээх газар нь өөр. Тиймээс эхлээд Android дээр туршина.

---

### Алхам 1.6 — Хийсвэр утас (emulator) үүсгэх

**Юу хийх:**
1. Android Studio → **More Actions** → **Virtual Device Manager**.
2. **Create Device** → `Pixel 7` → **Next** → хамгийн дээд талын системийн хувилбарыг татна → **Finish**.
3. ▶️ дарж асаагаад утас шиг дэлгэц гарч ирэхийг шалгана.

**Яагаад:** Апп ажиллуулахын тулд "утас" хэрэгтэй. Жинхэнэ утас холбож болох ч emulator нь утас, кабель, тохиргоогүйгээр шууд туршдаг тул эхлэхэд хамгийн амар.

---

### Алхам 1.7 — Бүх зүйл зөв эсэхийг шалгах

**Юу хийх:** VS Code → дээд цэснээс **Terminal → New Terminal**. Доор цонх нээгдэнэ. Тэнд бичнэ:

```bash
flutter doctor
```

Хэрэв "Android licenses not accepted" гэж гарвал:

```bash
flutter doctor --android-licenses
```

гээд бүх асуултад `y` гэж хариулна.

**Яагаад:** `flutter doctor` бол нэрнээсээ л "эмч". Таны компьютерийг шалгаж, юу дутуу байгааг жагсааж хэлнэ.
- ✓ = бэлэн
- ✗ = дутуу

**Android toolchain** ба **VS Code** мөрүүд ✓ байхад хангалттай. Xcode, Visual Studio гэсэн мөрүүд ✗ байж болно, бидэнд хэрэггүй.

`--android-licenses` бол Google-ийн хэрэглэгчийн гэрээг зөвшөөрөх үйлдэл. Үүнгүйгээр Android апп бүтээхийг хориглодог.

## 2-р хэсэг. Кодоо татаж аваад ажиллуулах

### Алхам 2.1 — Кодыг компьютер руугаа татах

**Юу хийх:** VS Code-ийн terminal дээр (мөр бүрийг тус тусад нь бичээд Enter):

```bash
cd C:\dev
git clone -b claude/tiny-room-app-k3n2q2 https://github.com/oyu8737-netizen/file-C-Users-oyu87-Downloads-Telegram-Desktop-NCPH_Public_Health_Intelligence_Dashboard_v4.html.git tiny-room-repo
```

**Яагаад, хэсэг бүрээр нь:**

| Хэсэг | Утга |
|---|---|
| `cd C:\dev` | **c**hange **d**irectory — "`C:\dev` хавтас руу ор". Файл хаана хадгалагдахыг сонгож байна |
| `git clone` | GitHub дээрх кодыг бүхэлд нь хуулж ав |
| `-b claude/tiny-room-app-k3n2q2` | **b**ranch — аль "салбар хувилбар"-ыг авахыг заана. Tiny Room код яг энэ салбарт байгаа |
| `https://github.com/...git` | Кодын онлайн хаяг |
| `tiny-room-repo` | Компьютер дээр үүсэх хавтасны нэр. Repo-ийн жинхэнэ нэр хэтэрхий урт тул богиносгов |

> 💡 **Branch гэж юу вэ?** Судалгааны өгүүллийн "ноорог хувилбар" шиг. Үндсэн хувилбарт шууд өөрчлөлт хийхгүйгээр тусад нь хөгжүүлээд, бэлэн болмогц нэгтгэдэг.

> Git ашиглахгүй бол: GitHub хуудас руу ороод **Code → Download ZIP** дарж татаад задална. Үр дүн нь адилхан.

### Алхам 2.2 — Кодын хавтсыг VS Code-оор нээх

**Юу хийх:** VS Code → **File → Open Folder** → `C:\dev\tiny-room-repo\tiny_room` хавтсыг сонгоно.

**Яагаад:** Flutter төсөл бол нэг файл биш, олон файлтай *хавтас*. VS Code хавтсыг бүхэлд нь нээснээр бүх файлыг зүүн талд харуулж, "энэ бол Flutter төсөл" гэдгийг таньдаг.

`tiny_room` хавтсыг сонгох нь чухал. Учир нь `pubspec.yaml` файл яг тэнд байгаа бөгөөд Flutter төслийг тэр файлаар нь таньдаг.

### Алхам 2.3 — Нэмэлт сангуудыг татах

**Юу хийх:** Terminal дээр:

```bash
flutter pub get
```

**Яагаад:** Манай апп бусдын бичсэн бэлэн кодыг (**package** буюу сан) ашигладаг. Жишээ нь `shared_preferences` нь coin-ийг утсан дээр хадгалах сан.

`pubspec.yaml` файлд "надад ийм сангууд хэрэгтэй" гэсэн **жагсаалт** л бий, сангууд өөрсдөө биш. `pub get` тэр жагсаалтыг уншаад интернэтээс татаж авдаг.

> Хоолны жор (pubspec.yaml) дээр "2 өндөг" гэж бичсэн ч өндөг өөрөө жорон дотор байдаггүй. Дэлгүүрээс авчрах хэрэгтэй (pub get).

### Алхам 2.4 — Аппыг ажиллуулах

**Юу хийх:**
1. Emulator-оо асаасан байлгана (Алхам 1.6).
2. Terminal дээр:

```bash
flutter run
```

Эхний удаа 3–10 минут орж магадгүй. Дараа нь emulator дээр апп нээгдэнэ.

**Яагаад:** `flutter run` нь гурван зүйл хийдэг:
1. Dart кодыг Android ойлгох хэлбэрт **хөрвүүлнэ** (build),
2. хөрвүүлсэн аппыг emulator руу **суулгана**,
3. **нээнэ**.

Эхний удаа удаан байдаг нь бүх зүйлийг анх удаа бүтээж байгаатай холбоотой. Дараагийн удаад өөрчлөгдсөн хэсгийг л дахин бүтээдэг тул хурдан.

**Апп ажиллаж байх үед terminal дээр:**

| Товч | Юу болох | Хэзээ хэрэгтэй |
|---|---|---|
| `r` | **Hot reload** — кодын өөрчлөлтийг 1 секундэд харуулна | Код засаад үр дүнг шууд харах |
| `R` | Бүрэн дахин эхлүүлэх | `r` ажиллахгүй үед |
| `q` | Зогсоох | Дууссан үед |

## 3-р хэсэг. Код хэрхэн зохион байгуулагдсан бэ

### Яагаад олон файлд хуваасан бэ?

Бүх кодыг нэг файлд бичиж болох ч 1,000 мөртэй нэг файлаас юм олох хэцүү. Эмнэлэг тасаг тасгаар хуваагддаг шиг кодыг **үүргээр нь** хуваадаг.

```
tiny_room/
│
├── pubspec.yaml          ← Төслийн "паспорт": нэр, хувилбар, хэрэгтэй сангууд
│
├── lib/                  ← ❤️ ТАНЫ КОД (library). Бүх гол зүйл энд
│   ├── main.dart         ← Апп ЭХЛЭХ цэг
│   │
│   ├── models/           ← "Юм" гэж юу вэ? (өгөгдлийн хэлбэр)
│   │   ├── furniture.dart    ← Тавилга: нэр, үнэ, эмодзи, нээгдэх нөхцөл
│   │   └── placed_item.dart  ← Өрөөнд тавьсан тавилга: хаана, хэдэн градус эргэсэн
│   │
│   ├── state/            ← "Тархи": тооцоо, дүрэм
│   │   └── game_state.dart   ← алхам→coin, streak, level, худалдан авах, хадгалах
│   │
│   ├── services/         ← Гадаад ертөнцтэй холбогдох
│   │   └── step_service.dart ← (LEVEL 2) HealthKit / Health Connect-оос алхам авах
│   │
│   ├── widgets/          ← Олон дэлгэцэнд давтан ашиглах хэсэг
│   │   └── room_view.dart    ← Өрөөний зураг (Home болон Editor хоёуланд)
│   │
│   └── screens/          ← Хэрэглэгчийн ХАРДАГ 5 дэлгэц
│       ├── home_screen.dart
│       ├── editor_screen.dart
│       ├── shop_screen.dart
│       ├── collection_screen.dart
│       └── profile_screen.dart
│
├── test/                 ← Автомат шалгалтууд
├── android/              ← Android-д зориулсан тохиргоо (автоматаар үүссэн, бараг хөндөхгүй)
└── ios/                  ← iPhone-д зориулсан тохиргоо (автоматаар үүссэн, бараг хөндөхгүй)
```

### Гол санаа: "Тархи" ба "Нүүр царай" тусдаа

```
  Хэрэглэгч товч дарна
          │
          ▼
  ┌───────────────┐   "5000 алхам нэм"   ┌──────────────────┐
  │   screens/    │ ───────────────────▶ │ state/           │
  │ (нүүр царай)  │                      │ game_state.dart  │
  │               │ ◀─────────────────── │ (тархи)          │
  └───────────────┘  "coin 50 боллоо,    └──────────────────┘
                      дэлгэцээ шинэчил"           │
                                                  ▼
                                          утсан дээр хадгална
```

**Яагаад ингэж хуваасан бэ?**
1. **Солиход амар.** LEVEL 2-т fake товчийг жинхэнэ алхмаар солиход "тархи" огт өөрчлөгдөхгүй. Зөвхөн алхам *хаанаас* ирэхийг л солино.
2. **Шалгахад амар.** Тестүүд дэлгэцгүйгээр зөвхөн "тархи"-г шалгаж чадна.
3. **Алдаа олоход амар.** Coin буруу тоологдвол `game_state.dart`, товч буруу газар байвал `screens/` гэж шууд мэднэ.

## 4-р хэсэг. Гол логикийг мөр мөрөөр нь

### 4.1 Тавилгыг хэрхэн тодорхойлсон бэ (`lib/models/furniture.dart`)

```dart
Furniture(id: 'chair', name: 'Сандал', emoji: '🪑', price: 100),
```

| Хэсэг | Утга |
|---|---|
| `Furniture(...)` | "Шинэ тавилга үүсгэ" |
| `id: 'chair'` | Компьютерт зориулсан давтагдашгүй нэр. Хадгалахад үүнийг ашиглана |
| `name: 'Сандал'` | Хэрэглэгчид харагдах нэр |
| `emoji: '🪑'` | Зураг (одоогоор эмодзи, хожим жинхэнэ зургаар солино) |
| `price: 100` | Үнэ (coin) |

Түгжээтэй тавилга:

```dart
Furniture(
  id: 'sofa', name: 'Буйдан', emoji: '🛋️', price: 300,
  unlockType: UnlockType.streak,   // нээгдэх нөхцөлийн ТӨРӨЛ: streak
  unlockValue: 7,                  // нөхцөлийн УТГА: 7 хоног
),
```

**Шинэ тавилга нэмэх бол** энэ жагсаалтад нэг мөр нэмэхэд л хангалттай. Дэлгүүр, Collection автоматаар шинэчлэгдэнэ. Нэг газарт өгөгдөл, олон газарт ашиглалт гэдэг зарчим.

### 4.2 Алхмыг coin болгох — хамгийн чухал функц (`lib/state/game_state.dart`)

**Функц** гэдэг нь нэр өгсөн, дахин дахин дуудаж болох заавар. `syncTodaySteps` функц "өнөөдөр нийт хэдэн алхам хийсэн" гэсэн **нэг тоо** хүлээж аваад бүх тооцоог хийдэг.

```dart
List<Furniture> syncTodaySteps(int stepsToday) {
```
> "`syncTodaySteps` нэртэй функц. `stepsToday` гэсэн бүхэл тоо (`int`) хүлээж авна. Хариуд нь шинээр нээгдсэн тавилгын жагсаалт буцаана."

```dart
  _rollDayIfNeeded();
```
> **Эхлээд шинэ өдөр эхэлсэн эсэхийг шалгана.** Хэрэв өчигдрийнх хэвээр байвал өдрийн тоолуурыг 0 болгоно.
> **Яагаад эхэнд нь?** Өчигдрийн 8,000 алхам дээр өнөөдрийнхийг нэмчихвэл буруу тооцоо гарна.

```dart
  if (stepsToday <= todaySteps) return const [];
```
> **Шинэ алхам байхгүй бол юу ч хийлгүй гар.**
> **Яагаад?** Утас нэг тоог хэд хэд илгээж магадгүй. Шалгахгүй бол нэг алхамд хоёр удаа coin өгнө.

```dart
  final newSteps = stepsToday - todaySteps;
  todaySteps = stepsToday;
  totalSteps += newSteps;
```
> **Шинээр нэмэгдсэн алхмыг олж, нийт алхамд нэмнэ.**
> Жишээ: өмнө 7,000, одоо 8,000 → шинэ = 1,000 → нийт алхам +1,000.
> (`+=` гэдэг нь "одоо байгаа дээр нь нэм" гэсэн үг.)

```dart
  final earned = todaySteps ~/ stepsPerCoin - coinsRewardedToday;
```
> **Энэ бол "incremental reward"-ын зүрх.**
> - `todaySteps ~/ stepsPerCoin` → өнөөдөр нийт хэдэн coin авах *эрхтэй* вэ. `~/` бол бүхэл хуваалт (8,050 ÷ 100 = **80**, үлдэгдлийг хаяна).
> - `- coinsRewardedToday` → өнөөдөр *аль хэдийн авсан* coin-ийг хасна.
> - Үлдсэн нь = **шинээр өгөх coin**.
>
> **Яагаад ингэж тооцоолсон бэ?** Энгийн арга буюу "шинэ алхам ÷ 100" хэрэглэвэл 50 алхмыг хоёр удаа хийхэд 0 + 0 = 0 coin болно. Үнэндээ 100 алхам хийсэн тул 1 coin авах ёстой. Манай арга нийлбэрээс тооцдог тул жижиг алхмууд **алдагдахгүй**.

```dart
  if (earned > 0) {
    coins += earned;
    coinsRewardedToday += earned;
  }
```
> Шинэ coin байвал хэтэвчинд нэмж, "өнөөдөр өгсөн" тоолуурт тэмдэглэнэ.

```dart
  _updateStreak();
  _save();
  notifyListeners();
```
> 1. **Streak шинэчлэх:** 5,000-д хүрсэн үү? Өчигдөр ч хүрсэн үү?
> 2. **Хадгалах:** Утсан дээр бичнэ. **Яагаад?** Аппыг хаагаад нээхэд coin алга болохгүйн тулд.
> 3. **Мэдэгдэх:** "Өгөгдөл өөрчлөгдлөө" гэж бүх дэлгэцэд хэлнэ. **Яагаад?** Ингэхгүй бол coin 50 болсон ч дэлгэц дээр 0 гэж харагдсаар байна.

### 4.3 Streak (`_updateStreak`)

```dart
if (todaySteps < dailyStepGoal || lastGoalDate == todayDate) return;
```
> "Зорилгод (5,000) хүрээгүй, **эсвэл** (`||`) өнөөдөр аль хэдийн тоолсон бол юу ч хийхгүй."
> **Яагаад хоёр дахь нөхцөл?** Нэг өдөр 5,000-аас дээш алхам хийх бүрд streak нэмэгдвэл нэг өдөрт 10 streak болчихно.

```dart
streak = lastGoalDate == yesterday ? streak + 1 : 1;
```
> `A ? B : C` гэдэг нь "A үнэн бол B, үгүй бол C".
> → "Өчигдөр ч зорилгодоо хүрсэн бол streak +1, үгүй бол 1-ээс дахин эхэлнэ."

### 4.4 Дэлгэц өгөгдлийг хэрхэн "хардаг" вэ

Дэлгэц бүрийн эхэнд ийм мөр бий:

```dart
final game = GameScope.of(context);
```
> "Тархи (GameState)-г надад өг." Ингэснээр дэлгэц `game.coins`, `game.todaySteps` зэргийг уншиж, `game.buy(...)` гэх мэт үйлдэл дуудаж чадна.
> **Яагаад `GameScope` гэж тусад нь?** 5 дэлгэц бүгд **нэг л** тархийг хуваалцах ёстой. Тус бүр өөрийн тархитай бол Shop дээр худалдаж авсан сандал Room Editor дээр харагдахгүй.

## 6-р хэсэг. Өөрөө анхны өөрчлөлтөө хийж үзэх

Суралцах хамгийн сайн арга бол **өөрөө өөрчлөөд үр дүнг нь харах**.

### Дасгал 1 — Coin-ийн харьцааг өөрчлөх

1. `lib/state/game_state.dart` файлыг нээнэ.
2. Энэ мөрийг олно:
   ```dart
   const int stepsPerCoin = 100;
   ```
3. `100`-г `50` болгоод хадгална (`Ctrl + S`).
4. Terminal дээр `r` дарна (hot reload).
5. `+1000` дарахад одоо **+20 coin** авах ёстой.

**Юу сурах вэ:** Нэг тоог өөрчлөхөд бүх апп даяар дүрэм өөрчлөгддөг. Тоо бүрийг кодын дотор тарааж бичихгүй, нэг **тогтмол** (`const`) болгон нэг газар тавьдагийн давуу тал нь энэ.

### Дасгал 2 — Шинэ тавилга нэмэх

1. `lib/models/furniture.dart` нээнэ.
2. `Furniture(id: 'chair', ...)` мөрийн **доор** нэмнэ:
   ```dart
   Furniture(id: 'cat', name: 'Муур', emoji: '🐈', price: 50),
   ```
3. Хадгалаад `R` (том R) дарна.
4. Shop дээр 🐈 Муур гарч ирнэ.

> ⚠️ Мөрийн төгсгөлийн **таслал** (`,`) болон **хаалт** (`(` `)`) маш чухал. Нэг л тэмдэгт дутвал VS Code улаанаар зурна. Тэгвэл Ctrl+Z дарж буцаагаад дахин оролдоорой.

### Дасгал 3 — Өрөөний өнгийг өөрчлөх

`lib/widgets/room_view.dart` дотор `Color(0xFFFFE8D6)` гэсэн мөрийг олно. `FFE8D6` хэсэг бол өнгөний код. https://htmlcolorcodes.com хаягаас дуртай өнгөө сонгоод (жишээ нь `D6EAFF` цэнхэр) сольж үзээрэй.
