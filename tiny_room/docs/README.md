## 📌 Бүх хичээлд мөрдөх 3 дүрэм

1. **Зөвхөн саарал хайрцаг доторхыг PowerShell-д хуулна.** Монгол тайлбар, хүснэгт нь уншихад зориулсан.
   ```powershell
   энэ мэт хайрцаг доторхийг л хуулна
   ```
2. **Доод мөрөнд `PS C:\...>` гарвал ажил дууссан.** Гараагүй бол ажиллаж байгаа тул хүлээнэ.
3. **PowerShell дотор `Ctrl + C` = ЗОГСООХ.** Хуулахдаа хулганаар сонгох, тавихдаа хулганы баруун товч ашиглана.
