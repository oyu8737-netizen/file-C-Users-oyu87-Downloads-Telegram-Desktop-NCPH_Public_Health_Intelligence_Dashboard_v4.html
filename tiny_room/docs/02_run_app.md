## Алхам 2.1 — Кодоо анх удаа татах (нэг л удаа)

```powershell
cd $HOME; git clone -b claude/tiny-room-app-k3n2q2 https://github.com/oyu8737-netizen/file-C-Users-oyu87-Downloads-Telegram-Desktop-NCPH_Public_Health_Intelligence_Dashboard_v4.html.git tiny-room-repo
```

| Хэсэг | Утга |
|---|---|
| `cd $HOME` | Өөрийн хувийн хавтас руу ор (`C:\Users\Oyu-Erdene`) |
| `git clone` | GitHub-аас кодыг хуулж ав |
| `-b claude/tiny-room-app-k3n2q2` | Аль **салбар хувилбар**-ыг авах вэ |
| `tiny-room-repo` | Компьютер дээр үүсэх хавтасны нэр |

> Аль хэдийн татсан бол энэ алхмыг алгасна.

## Алхам 2.2 — Шинэ код гарсан бол шинэчлэх (дараа дараагийн удаад)

```powershell
cd $HOME\tiny-room-repo; git stash -u; git pull; cd tiny_room; flutter pub get
```

| Хэсэг | Утга |
|---|---|
| `git stash -u` | Таны компьютер дээрх өөрчлөлтийг **түр хадгалж** хажуу тийш тавина (устгахгүй) |
| `git pull` | GitHub-аас шинэ кодыг татна |
| `flutter pub get` | Шинэ сангуудыг татна |

## Алхам 2.3 — Chrome дээр нээх

```powershell
cd $HOME\tiny-room-repo\tiny_room; flutter run -d chrome
```

⏳ 1–2 минутын дараа Chrome дээр **МИНИЙ ӨРӨӨ** гарч ирнэ. 🏠

### Апп ажиллаж байх үед PowerShell дээр

| Товч | Юу болох |
|---|---|
| `r` | Кодоо өөрчилсөн бол 1 секундэд шинэчилнэ (hot reload) |
| `R` | Бүрэн дахин эхлүүлнэ |
| `q` | Аппыг хаана |

### Энэ мөрүүд гарвал хэвийн ✅

| Мөр | Утга |
|---|---|
| `Firebase тохируулаагүй тул offline горим` | Firebase-ийг хараахан холбоогүй ([Хичээл 4](04_firebase.md)) — апп ажиллана |
| `Could not find a set of Noto fonts...` | Зарим эмодзи/үсгийн фонт хайж байна — нөлөөгүй |
