## 📱 Android

### 5.1 Утсаа "хөгжүүлэгчийн горим"-д оруулах (нэг удаа)

1. **Settings → About phone** → **Build number** дээр **7 удаа** дарна → "You are now a developer!"
2. **Settings → Developer options** → **USB debugging** асаана.

> **Яагаад:** Компьютер утас руу апп суулгахыг Android анхандаа хориглодог.

### 5.2 Суулгах

1. Утсаа USB-ээр холбоно → утсан дээр **"Allow USB debugging?"** → **Allow**.
2. PowerShell:
   ```powershell
   cd $HOME\tiny-room-repo\tiny_room; flutter run
   ```
3. Апп нээгдмэгц **Гэр** → **Алхам холбох** → бүх зөвшөөрлийг **Allow**.

### Алхам хаанаас ирдэг вэ?

| Утас | Эх сурвалж | Апп хаалттай байхад |
|---|---|---|
| Android 14+ | **Health Connect** (суучихсан) | ✅ тоологдоно |
| Хуучин Android + Health Connect суулгасан | Health Connect | ✅ тоологдоно |
| Хуучин Android, Health Connect-гүй | Утасны **мэдрэгч** | ❌ Апп нээлттэй үед л |

> "Health Connect суулгах" товч гарвал дарж Play Store-оос суулгахыг зөвлөж байна.

## 🍎 iPhone

Apple Health-ээс алхам уншдаг **жинхэнэ апп** бүтээхэд **Mac + Xcode** заавал хэрэгтэй (Apple-ийн дүрэм).

Mac дээр:
```bash
cd tiny_room && flutter run
```
Xcode → **Runner → Signing & Capabilities → Team** сонгоно. HealthKit тохиргоо бэлэн хийгдсэн.
> HealthKit-д Apple Developer бүртгэл ($99/жил) шаардагдаж магадгүй.

Mac байхгүй бол: [Хичээл 6](06_share.md)-ийн **вэб холбоос**-оор iPhone-ы нүүр дэлгэцэд нэмнэ (алхам тоологдохгүй).
