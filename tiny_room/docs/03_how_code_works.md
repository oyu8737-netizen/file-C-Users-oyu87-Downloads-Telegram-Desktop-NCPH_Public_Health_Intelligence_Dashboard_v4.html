## 3.1 Гол санаа: "Тархи" ба "Нүүр царай" тусдаа

```
  Хэрэглэгч товч дарна / утас алхам тоолно
          │
          ▼
  ┌───────────────┐   "5000 алхам нэм"   ┌──────────────────┐     ┌─────────────┐
  │   screens/    │ ───────────────────▶ │ state/           │ ──▶ │ утсан дээр  │
  │ (нүүр царай)  │ ◀─────────────────── │ game_state.dart  │     │ + ☁️ cloud  │
  └───────────────┘  "coin өөрчлөгдлөө"  │ (тархи)          │     └─────────────┘
                                         └──────────────────┘
```

**Яагаад ингэж хуваасан бэ?**
- **Солиход амар:** Туршилтын товчийг жинхэнэ алхмаар сольсон ч "тархи" өөрчлөгдөөгүй.
- **Шалгахад амар:** 19 автомат тест дэлгэцгүйгээр тархийг шалгадаг.
- **Алдаа олоход амар:** Coin буруу бол `game_state.dart`, товч буруу бол `screens/`.

## 3.3 Алхам → Coin: хамгийн чухал 3 мөр

`lib/state/game_state.dart` доторх `syncSteps` функцээс:

```dart
final earned = rec.steps ~/ stepsPerCoin - rec.coinsFromSteps;
```
> Тухайн өдөр **нийт авах ёстой** coin − **аль хэдийн авсан** coin = **шинэ** coin.
> Ингэснээр нэг алхамд **хоёр удаа** coin өгөхгүй, жижиг алхмууд ч **алдагдахгүй**.

```dart
if (rec.goalReached && !rec.goalBonusGiven) { ... }
```
> Өдрийн зорилгод **анх** хүрэхэд л bonus өгнө (өдөрт нэг удаа).

```dart
game.mergeRemote(remote);
```
> **Өөр утсан дээр нэвтрэхэд:** cloud-ын өрөө, coin үндэс болж, энэ утсан дээрх илүү алхам нэмэгдэнэ.

## ✏️ Дасгал — өөрөө өөрчилж үзэх

Апп `flutter run -d chrome`-оор ажиллаж байх үед:

**Дасгал 1 — Coin-ийн харьцаа.** `lib/state/game_state.dart` → `const int stepsPerCoin = 100;` → `50` болгож `Ctrl+S` → PowerShell дээр `r`. `+1000` дарахад **+20 coin** болно.

**Дасгал 2 — Шинэ тавилга.** `lib/models/furniture.dart` → жагсаалтад нэмнэ:
```dart
  Furniture(id: 'cat', nameMn: 'Муур', nameEn: 'Cat', nameZh: '猫', emoji: '🐈', price: 50),
```
→ `Ctrl+S` → `R`. Дэлгүүрт 🐈 гарна.

**Дасгал 3 — Монгол загварын цонх.** `lib/l10n/app_lang.dart` → `windowView: '🏔️'` → `'🐑'` болгоно → `R`. Цонхоор хонь харагдана.

> ⚠️ Таслал `,`, хаалт `( )` чухал. Улаан зураас гарвал `Ctrl+Z`.
